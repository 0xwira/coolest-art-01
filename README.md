# The Lantern Kitsune

Entry for make.fun coolest-art-01 ("Make the coolest art").

A colossal nine-tailed white fox carries a tiny lantern-lit shrine
village on its back; strings of paper lanterns trace its nine flowing
tails across a deep-blue night sky while pilgrims with lanterns walk
the valley path far below.

## How it runs

`main.py` (Python 3.13, standard library only) parses and validates
the bundled `artwork.jpg` (1024x683) against the competition image
gate, then writes it to `/output/entry.png` (or `$MAKEFUN_OUTPUT_DIR`).
